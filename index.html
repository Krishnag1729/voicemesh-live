How it works

Browser (16 kHz audio) → gateway (auth, admission control, sticky routing, replay buffer) → worker on an RTX 3050: streaming FastConformer ASR → clause segmenter → IndicTrans2 English→Hindi → Piper Hindi TTS → Opus back to you. The same back end serves the VoiceMesh Android app.

Research demo for a course project. Adults only. Audio is processed live and never stored; server logs hold counters only, no text or audio. Hindi voice is for non-commercial research use.
